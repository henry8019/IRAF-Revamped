# Reporting a vulnerability · 安全问题报告

Use [GitHub private vulnerability reporting](https://github.com/henry8019/IRAF-Revamped/security/advisories/new) for suspected security issues in the workbench, launchers, or distributed frontend. Reports against the current `main` branch are welcome. Include the affected commit, operating system, steps to reproduce, and expected impact. Remove private observations, credentials, and the session token from any example or browser URL.

如发现工作台、启动器或随仓库分发的前端存在安全问题，请通过上面的 GitHub 私密入口联系维护者。请注明提交号、系统、复现步骤和影响。提交示例前请移除私有观测数据、凭据以及浏览器地址中的会话令牌。普通功能故障可在公开 Issues 中报告。
